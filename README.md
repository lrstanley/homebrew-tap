# homebrew-tap

[Homebrew](https://brew.sh) tap for my projects. GoReleaser writes the casks in
[`Casks/`](Casks) when a project publishes a release, so don't edit them by hand.

## Usage

```console
$ brew install lrstanley/tap/<name>
```

Or tap once, then install by name:

```console
$ brew tap lrstanley/tap
$ brew install <name>
```
